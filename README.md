# مشروع إدارة الودائع والاستثمارات — مجموعة العسافي
## AL-ASAFY GROUP Deposit & Investment Management System

نظام متكامل لإدارة ودائع المستثمرين، وحساب وتجميع الأرباح الشهرية والتراكمية، ومتابعة طلبات السحب وتصدير التقارير المالية (PDF / Excel).

### المميزات الرئيسية:
- **إدارة المستثمرين**: إضافة وتعديل وعرض بيانات ووثائق المستثمر.
- **إدارة الودائع**: ودائع بالدينار العراقي (IQD) والدولار (USD) مع تحديد دورية الصرف ونسبة الأرباح.
- **إعلان النسب والأرباح الشهري**: احتساب وتجميع دقيق بحسب الذكرى الشهرية للوديعة (Anniversary Date) ومنع التكرار (Idempotency).
- **صرف الأرباح التراكمية وطلبات السحب**: متابعة وإيصالات رسمية `AG-YYYYMM-XXXXXX` وسحوبات الأرباح.
- **بوابة المستثمر**: لوحة تحكم خاصة بكل مستثمر لمتابعة حساباته وتقديم طلبات السحب.
- **النشر والتحديث الآلي**: ربط وتحديث آلي ومستمر عبر GitHub Actions وسيرفرات Namecheap.
